Connect Resend or change your API key

In Nushell, stop the existing tracker and enter your key at the private prompt. Use a verified sender domain to email other recipients.

$env.EMAIL_PROVIDER = "resend"
$env.RESEND_API_KEY = (input --suppress-output "Resend API key: " | str trim)
$env.RESEND_FROM = "RobloxStats <reports@your-verified-domain.com>"
uv run robloxstats

Replace the sender above with your actual verified address. Your API key stays out of source code and the dashboard. These variables last for this terminal session.
